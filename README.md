# 💰 Personal Expense Tracker

A beginner-friendly Python command-line application to record personal expenses, view expense records, calculate total spending, and filter expenses by category.

## 📌 Features

- **Add Expenses** – Enter expense name, amount, and category.
- **View Expenses** – Display all recorded expenses.
- **Total Spending** – Calculate the total amount spent.
- **Category Filtering** – View expenses belonging to a specific category.
- **Simple Menu Interface** – Easy-to-use menu with five options.
- **Input Handling** – Handles invalid menu selections.

## 🛠️ Technologies Used

- Python 3
- VS Code

## 📚 Concepts Practiced

- Lists and tuples
- `for` loops
- Conditional statements (`if`, `elif`, `else`)
- User input using `input()`
- List comprehensions
- `sum()` function
- f-strings
- `break` statement
